# ReelFlow releases

Official distribution repository for ReelFlow Windows installers and signed update artifacts.

Website: https://reelflow.site

## Downloads

See the Releases section for installers and validation builds. Releases marked **pre-release** are for validation, and are not the stable automatic-update channel.

The initial U1 validation build does not include the in-app updater yet. The updater bootstrap will be released after its runtime and safe-install checks are complete.

Only public distribution files and release metadata belong here. Account credentials and private signing keys are not distributed with installers.
